## **🚩 Stage 2 - Start with Python & Data Analysis basic** (2 months)

### 🎯 Objectives:
- Python Programming:
  - Master Python fundamentals: variables, data types, operators, conditions, loops, functions, and OOP.
  - Work with strings, lists, dictionaries, sets, tuples.
  - File I/O and JSON data manipulation.
  - Build basic applications using the IPO model and Streamlit.
  - Introduction to Git, IDEs (VSCode), and Jupyter Notebook  
- Data Analysis Foundations:
    - Use NumPy and Pandas for data wrangling and analysis
    - Perform data cleaning, filtering, and aggregation on real-world datasets
    - Visualize data using Matplotlib and Seaborn
    - Automate Excel reports using xlwings
    - Build interactive dashboards with Streamlit
    - Use APIs to integrate basic AI features (e.g., chatbot)
- Problem Solving & Algorithmic Thinking:
    - Apply logic and algorithmic patterns to solve real-world problems
    - Use flowcharts and structured thinking to model solutions


### 📚 Recommended Resources:


### 💻 Projects:
- Sales Report Automation Tool
    - Clean and analyze supermarket sales data using Pandas.
    - Generate visual reports and export to Excel using xlwings.
- Interactive Dashboard: Customer Churn Analysis
    - Visualize Telco Customer Churn dataset with Streamlit.
    - Apply filters, show charts, and explain churn rates.
- AI Chatbot with Streamlit + OpenAI API
    - Simple chatbot that interacts with user input.
    - Use basic NLP + API call integration (bonus for creativity).

## **🚩 Stage 3 - Introduction to Machine Learning** (3 months)

### 🎯 Objectives
- Data preprocessing, model evaluation & tuning
- Understand the basics of machine learning algorithms: Linear Regression, kNN, Decision Tree
- Know how to train models with scikit-learn, supervised/unsupervised learning
- Work with data: normalization, train/test split, performance measurement

### 🔧 Skills:
- Scikit-learn
- Pre-train data
- Evaluation Metrics: Accuracy, Precision, Recall
- Overfitting, Underfitting, Cross-validation

### 📚 Recommended Resources
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)
- Book: *Hands-On Machine Learning with Scikit-learn, Keras & TensorFlow* (Chapters 1–6)

### 💻 Practice Projects
1. **Home Price Prediction Project (Boston Housing)**: Predicting home prices based on multiple features (Linear Regression, Decision Tree).

2. **Email Spam Classification Project**: Using Naive Bayes algorithm to classify emails as spam or not.
